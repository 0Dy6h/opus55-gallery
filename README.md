# 螃蟹的 Opus 5.5 作品集

一个纯本地静态页面,收集网上散落的 **Claude Opus 5.5**(Anthropic,2026-09-22 发布)作品:
视频、游戏、视觉艺术、研究实验、实战应用、评测文章与官方材料,目前共 52 件,其中 24 件可在页内直接观看。

## 怎么打开

双击 `index.html` 即可(不需要服务器,纯本地文件,所有动效为原生 Canvas/CSS 3D 实现)。

**页内放映**:24 部作品可以直接在本页看。其中 22 部视频的 mp4 **不入库**(约 980MB，
涉及他人作品版权，见文末说明),所以:

- **作者本机**:mp4 在 `media/` 里，点开就在页内播放(断网也能放)。
- **你 clone 下来后**:没有 mp4 文件，点开会自动出现「▶ 在线观看原作 ↗」按钮，一键跳到
  原作者页面观看——每件作品在 `works.js` 里都记了原始链接(`url` 字段)与来源站点。
  封面图已随仓库提供,所以作品网格能完整浏览。

另 2 部互动网页作品(《奥兹曼迪亚斯》《The Golden Ford》)在弹层里内嵌运行(需联网)。
点卡片封面、放映厅横栏或首屏「开始放映」都会打开放映弹层:`←`/`→` 上一部/下一部、空格暂停、`F` 全屏、`Esc` 关闭。

其他功能:放映厅横栏 / 每张卡片带封面图(没有封面的自动生成分类色封面)/ 3D 粒子星域背景 / 旋转 3D 立方体 /
卡片 3D 倾斜跟随 + 流光 / 分类筛选 / 「页内可看」筛选 / 关键词搜索(按 `/` 聚焦、`Esc` 清空)/
按「最新发布」或「热度最高」排序 / 点 ☆ 收藏(存浏览器 localStorage,可只看收藏)/ 顶部滚动进度条。
系统开了「减少动态效果」时自动降级为静态版。

## 怎么新增作品

编辑 `works.js`,复制任意一条记录、改字段,保存后刷新页面即可:

```js
{
  id: "唯一英文id",                    // 不能和已有的重复
  title: "作品标题",
  cat: "video",                       // video / game / art / research / build / article / official
  url: "https://作品地址",
  discuss: "https://news.ycombinator.com/item?id=…",  // HN/社区讨论帖,没有填 null
  video: "media/xxx.mp4",             // 可选:本地视频路径,文件放 media/ 目录,填了就能页内放映
  poster: "media/xxx.jpg",            // 可选:封面图;不填自动生成分类色封面
  dur: 90,                            // 可选:视频时长(秒),封面右下角显示 1:30
  embed: "https://…",                 // 可选:没有 mp4 的互动网页作品,填了就在放映弹层里 iframe 内嵌运行(需联网)
  date: "2026-09-28",                 // YYYY-MM-DD
  source: "域名",                      // 如 launchvideo.io
  pts: 423,                           // HN 分数,没有填 null
  cmt: 221,                           // HN 评论数,没有填 null
  desc: "一句话中文介绍",
  tags: ["标签1", "标签2"]
}
```

分类补全在 `index.html` 顶部的 `CATS` 表里,想加新分类先去那里登记颜色。

## 数据来源与更新

- Hacker News(Algolia API,检索词 `opus 5.5`,按热度人工筛选)
- Anthropic 官方发布页 https://www.anthropic.com/claude-opus-5-5
- bilibili(检索「Opus 5.5」按作品人工筛选,视频取自本机 B 站客户端缓存;共 7 件,见视频分类)
- 收录截至 **2026-09-30**(模型发布后第 8 天;从 HN「opus 5.5」相关 40 帖、官方早期探索作品与 bilibili 中筛得 52 件)
- 官方也维护过一个「早期探索」作品串:https://twitter.com/claudeai/status/2102471866635919731
- `media/` 目录含作品的本地视频与封面(抓取自原作者公开发布页:X、YouTube、bilibili、reddit、echohive),仅供本地个人浏览,请勿二次分发;页面点击播放、不自动播放。其中 **22 个视频(约 980MB)按 `.gitignore` 不入库**——涉及他人作品版权,不便公开分发;每件作品的 `url` 字段保留了原作者链接,clone 后点「▶ 在线观看原作」即跳转观看。**封面图(jpg)随仓库提供**,用于作品网格展示。

## 文件结构

```
螃蟹的opus5.5作品集/
├── index.html   # 页面本体(样式、逻辑都在这一个文件里)
├── works.js     # 作品数据(52 条),日常维护只动这个文件
├── media/       # 作品本地视频 <id>.mp4 与封面 <id>.jpg(works.js 的 video/poster 字段引用)
├── .tools/      # 下载/转码工具(yt-dlp、ffmpeg),非站点本体,可整目录删除
└── README.md
```
